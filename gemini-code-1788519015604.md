# TASK: Build GuardRail-Agent (CLI + CI/CD Drift Engine for AI Codebases)

You are an expert Principal AI Security Engineer and Python Architect. Your objective is to build, test, and package **GuardRail-Agent** from scratch. 

GuardRail-Agent is a developer tool and CI/CD gate that prevents AI coding agents (Claude Code, Cursor, Aider, Copilot) from introducing hallucinated dependencies (slopsquatting), architectural drift (layer boundary violations), and subtle security bypasses.

Follow the instructions phase-by-phase. Do not jump ahead until tests for each phase pass.

## Technical Stack & Constraints
* **Language:** Python >= 3.11
* **CLI Framework:** `typer` or `click` + `rich` for terminal UI
* **Networking:** `httpx` (async HTTP for PyPI checks)
* **Configuration:** `tomli` / `tomllib` (Python standard library in 3.11+)
* **AST / Parsing:** `tree-sitter` and `tree-sitter-python`
* **Testing:** `pytest`, `pytest-asyncio`, `respx` (for mocking HTTP PyPI queries)
* **Output Standard:** Console table (`rich`) and machine-readable SARIF format (`sarif-om` or raw JSON)
