Enterprise-Grade Code Guardrails v2.0 PENTEST AGENT

A fully autonomous security engine that reasons before it acts.

Autonomous Pentest Agent (AI Reasoning)

Powered by the Gemini/Claude engine. GuardRail profiles your entire codebase (tech stack, attack surfaces, payment layers) to dynamically orchestrate and prioritize relevant security checks. It doesn't just scan; it thinks, acts, and writes a senior-level executive narrative.

Real-time Web Dashboard & Delivery

Stream the agent's live thought processes via WebSockets/SSE on a sleek local dashboard. Upon completion, it automatically generates professional, branded PDF reports (via ReportLab) and dispatches them straight to your email.

Secrets & Credentials Leakage

Advanced Shannon entropy analysis and regex validation detects high-value secrets (AWS, Stripe, JWTs) hidden in code, commit history, and hallucinated `.env` patterns.

OWASP Top 10 Precision Scanning

Leverages Tree-Sitter AST—not regex—to pinpoint SQL Injections, Command Injections, and Deserialization vulnerabilities with zero false positives on docstrings.

PyPI Slopsquatting & CVE Detection

Validates dependencies asynchronously against live OSV.dev vulnerability databases and PyPI registries to catch supply chain poisoning before execution.

Architectural Drift & API Security

Enforces modular boundaries via `.drift-rules.toml`. Flags unauthenticated routes, missing rate limits, and IDOR patterns across modern frameworks.

Native IDE MCP Server

Plugs directly into Antigravity, Claude Desktop, and Cursor via the Model Context Protocol (`mcp>=1.0.0`). AI agents verify their own code contextually in real time.
